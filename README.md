 🦉 Vocab · Learn English B2+ → C1

Interactive flashcard app for advanced English learners. Master vocabulary, phrasal verbs, idioms, and practice conversation in 6 months.

 ✨ Features

- 150+ C1-level wordswith definitions, examples, and Russian translations
- 70+ phrasal verbs organized by base verb (be, get, take, come, go, put, turn, break, give, look, make, bring, run, set, call, keep)
- 50+ idioms with context and full Russian translations
- Audio pronunciation 🔊 (native English speaker voice)
- Word lookup in definitions — tap any word to see its meaning instantly
- Three learning modes:
  - Words: C1 vocabulary
  - Phrasal: verb combinations
  - Idioms: common expressions
  - Talk: conversation scenarios (interview, small talk, disagreement, planning, café)
- Progress tracking:daily goals, streak counter 🔥, XP system
- Unlockable skins 🎨 (Aurora, Mint, Sunset, Ocean, Rosé, Gold) — earn XP to unlock
- Duolingo-inspired UI with gradient buttons and smooth animations
- Offline-first: all data stored locally (localStorage)
- Mobile-optimized: works great on phones as a home-screen web app

 🚀 How to Use

1. Open the app: [Live version](https://username.github.io/Vocabulary/) or download `index.html`
2. Choose a mode: Words, Phrasal, Idioms, or Talk
3. Learn:Tap to reveal definitions, tap again for Russian
4. Add words:Custom words feature lets you build your own deck
5. Unlock skins: Reach XP milestones to change the theme

 🎯 Learning Goals

- Reach C1 level in 6 months
- Master 150+ advanced vocabulary items
- Internalize phrasal verbs through repeated exposure
- Practice real conversations through scenario dialogues
- Build a sustainable daily habit (10 words/day)
